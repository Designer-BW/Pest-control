# Star Pest Control: prototype homepage

A single-page prototype for Star Pest Control in Gaborone, covering commercial, residential and industrial pest control.

## Run it
- Open `index.html` directly in a browser, **or**
- With Node.js installed: `npm start`, then visit http://localhost:3000

## Stack
- HTML5, pure CSS (`css/style.css`), vanilla JS (`js/main.js`)
- Bootstrap 5.3.8 + Bootstrap Icons 1.13.1 (CDN)
- Fonts: Inter (headings), Playfair Display (body)
- Images: Pexels (hot-linked from images.pexels.com)
- `server.js`: zero-dependency Node static server

## Notes
- All nav and CTA links are display-only (prototype).
- The quote form validates and shows a confirmation, but sends nothing.
- Phone numbers, emails, address, testimonials and stats are placeholders.
- Prices are in Botswana Pula (P).
